# Human Review Templates

This folder contains templates for manually reviewing the files generated by
`scripts/rag/summarizer.py`.

## Review inputs

For each case, compare:

- `summarizer_results/<project>/case_<id>/summarizer_result.json`
- the matching original log sequence in `data/sample/experiment_samples.csv`
- the matching retrieval output (retrieved_candidates.json) under `retrieval_results/`

The two generated fields to review are:

1. `response`, especially the items listed after `Filtered Relevant Items:`
2. `external_knowledge_summary`

## Suggested workflow

1. Copy `per_file_review_template.md` once for each `summarizer_result.json`.
2. Record a judgment for both fields: `Correct`, `Partially correct`, or `Incorrect`.
3. Record evidence for incorrect judgments, omissions, and inconsistencies.
4. Explicitly record false positives and false negatives:
   - **False positive:** a retained retrieval result that is irrelevant or weakly related.
   - **False negative:** a relevant retrieval result that was incorrectly omitted.
5. Complete `overall_assessment_template.md` after the per-file reviews.

Keep the original generated JSON unchanged; write annotations in `human_review` folder.
